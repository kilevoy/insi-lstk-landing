# ИНСИ ЛСТК — второй вариант лендинга

Новая версия размещена отдельно: https://kilevoy.github.io/insi-lstk-landing/v2/

Первый вариант в корневом `index.html` и его ресурсы сохранены.

## Что входит

- Адаптивная страница с четырьмя формами профилей и крупными согласованными визуализациями.
- Чертежи с H, B₁/B₂, C₁/C₂, t и R; комплект четырёх SVG в ZIP.
- 68 строк сортамента, поиск и добавление нескольких позиций в запрос.
- Термопросечка по ТУ ИНСИ и пробивной инструмент LGS-2.
- Обновлённый каталог на 7 страницах и исходный сертификат.
- Форма, которая готовит письмо EML с вложениями, а также позволяет сохранить или скопировать текст.

## Заявки

GitHub Pages обслуживает статические файлы. В текущей конфигурации форма **не отправляет** письмо и не сообщает о состоявшейся отправке. Она создаёт локальный черновик EML: пользователь открывает его в совместимой почтовой программе и отправляет на `zakaz@insi.ru`. Можно скопировать текст и отправить вручную, приложив исходные файлы.

Для автоматической отправки задайте HTTPS-адрес обработчика в `public/site.config.js` и пересоберите. Публичный файл не должен содержать ключи или пароли.

Контракт: `POST multipart/form-data`, поле `payload` — JSON по `lib/lead-validation.ts`, поля `files` — вложения. До 5 файлов, по 5 MiB, суммарно до 12 MiB. Успешный ответ: HTTP 2xx и JSON `{ "reference": "номер заявки" }`. Обработчик должен разрешать origin `https://kilevoy.github.io`, повторно проверять данные, принимать файлы и реально доставлять или сохранять обращение. Ошибка: не-2xx с JSON `{ "error": "понятное сообщение" }`.

## Сборка

Из этой папки: `npm ci`, затем `npm run typecheck` и `npm run build`.

Результат сборки записывается **только в `/v2/` репозитория**, корневой первый вариант не затрагивается. Содержимое страницы предварительно включено в HTML и доступно до загрузки JavaScript.

`src/` — React + TypeScript; `components/` — используемые Shadcn-компоненты; `public/` — файлы для сайта. `scripts/create-catalogue.py` обновляет PDF (ReportLab, PyMuPDF, Pillow и Inkscape).

## Техническая точность

- Визуализации не являются фотографиями изготовленных изделий. Отверстия показаны как пример.
- Сортамент извлечён из предоставленного каталога ИНСИ; диапазоны не гарантируют производство любого сочетания размеров или наличие на складе.
- У сигмы показаны основные размеры. Прежние противоречивые соответствия k/S/h исключены; геометрию рифа согласовывают по чертежу.
- Термопросечка ТПП: прорези 75 × 3 мм, продольная перемычка 25 мм, период 100 мм, смещение рядов 50 мм, поперечная перемычка 6,5 мм — рисунок А.3 ТУ 25.11.23-002-00206227-2020.
- Диаметры инструмента LGS-2: 12, 13, 14, 18, 22 мм. Расчёт узлов и схема крепежа не назначаются лендингом.

Проверены сборка, TypeScript, локальные ссылки, исходный вариант по Git-хешам, а также русские поля и точность вложения в EML. Страницы PDF проверены после рендеринга. Проверки в браузере в этом проходе не выполнялись.
